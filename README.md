# ZCB / Digital Systems

A terminal-inspired personal portfolio built as a lightweight static site.

## Customize

Edit `site.config.js` to replace the identity, contact details, project entries,
field notes, and external links. Project images live in `assets/`.

## Preview

Serve the directory with any static file server, for example:

```powershell
npx http-server . -p 4173 -c-1
```
